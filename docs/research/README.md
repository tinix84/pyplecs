# Research

Findings and where they came from. One file per question, named
`YYYY-MM-DD-<question>.md`.

## Rules

1. **Findings and sources only.** What was looked up, what it said, and the URL
   or file it came from. An ADR may cite a file here, which is why this
   directory is tracked.
2. **No decisions.** A finding that settles a choice becomes an ADR; link to it
   from the finding rather than deciding here.
3. **No status.** Nothing here is open, closed, or blocked — that belongs to the
   issue that asked the question.
4. **Dated and never revised.** A finding records what was true when it was
   looked up. New information is a new file, not an edit.
